## ✨ Key Features & Interactivity

- 🌓 **Dynamic Theme Switcher**: Full Dark & Light mode toggle with smooth transitions and `localStorage` persistence.
- 📊 **Reading / Scroll Progress Bar**: Real-time progress tracker anchored at the top of the viewport.
- 🎯 **Interactive 3D Hero Visual**: Dynamic parallax and perspective tilt effect tracking cursor position on desktop.
- 🗂️ **Filterable Project Showcase**: Categorized project filter (`All`, `Full-Stack & Web`, `AI & Data Science`, `Cloud & DevOps`) with animated card transitions.
- ⏱️ **Dual-Mode Interactive Timeline**: Seamless tab switching between **Work Experience** (Pacawood, Kistechnosoftware) and **Education** (SKIT Jaipur, RBSE Distinctions).
- 📜 **Verified Certifications Grid**: Detailed showcase of credentials (Copado AI DevOps ID: 062322, OCI Data Science, OCI AI, IIT Bombay C++ 85%).
- 📋 **One-Click Quick Copy with Toast Notifications**: Instant copy buttons for email and phone number with animated feedback.
- ✉️ **Functional Contact Form**: Direct message launcher with pre-formatted email composition.
- ⚡ **Zero-Build Architecture**: 100% pure vanilla HTML5, CSS3, and JavaScript — lightning fast, zero bundle size, and natively deployable to GitHub Pages.

## 🚀 How to Run Locally

Because this project uses vanilla web standards with no compilation steps required:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mbajeria/manish-portfolio.git
   cd manish-portfolio
   ```

2. **Open in any browser:**
   - On macOS:
     ```bash
     open index.html
     ```
   - On Linux:
     ```bash
     xdg-open index.html
     ```
   - Or using Python's built-in local server:
     ```bash
     python3 -m http.server 8000
     ```
     Then open `http://localhost:8000` in your web browser.

---

## 🌐 Deploy to GitHub Pages

To host this portfolio live with a free custom URL (`https://mbajeria.github.io/manish-portfolio`):

1. Push your latest changes to the `master` or `main` branch.
2. Go to your repository on GitHub: **Settings** → **Pages**.
3. Under **Branch**, select `master` (or `main`) and root folder `/ (root)`.
4. Click **Save**. Your site will be published within 1–2 minutes!
